## Introduction

This package contains shared code used by both the cloud and on-premise
variants of the 51Degrees IP intelligence engines for the
[51Degrees Pipeline API](https://51degrees.com/documentation/index.html?utm_source=github&utm_medium=readme&utm_campaign=51degrees-python&utm_content=fiftyone_ipintelligence_shared-readme.md&utm_term=introduction).

It is not intended to be used directly. See
[fiftyone_ipintelligence](https://pypi.org/project/fiftyone-ipintelligence/)
instead.

## Folders

- `fiftyone_ipintelligence_shared` - contains evidence key constants, example
  constants and utility functions shared by the IP intelligence packages.
- `tests` - unit tests.

## Requirements

* Python 3.8+
* The `fiftyone_pipeline_core`, `fiftyone_pipeline_engines`,
  `fiftyone_pipeline_cloudrequestengine` and
  `fiftyone_pipeline_engines_fiftyone` packages
